# Browser logos

Source: https://github.com/alrra/browser-logos/tree/58881b84c4d73adc03c06fa2c275a7abee02d935

Chrome, Edge, Firefox, Opera, Brave and Vivaldi use their SVG assets from src/<browser>/. Yandex uses src/yandex/yandex_64x64.png. Assets are bundled with the app and do not make network requests.
